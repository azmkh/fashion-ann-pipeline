# Fashion ANN Pipeline

This project implements a reproducible Fashion-MNIST classification pipeline
using TensorFlow, Git, and DVC.

## Pipeline stages

1. Prepare raw Fashion-MNIST data.
2. Preprocess and normalize the data.
3. Train a fully connected ANN.
4. Evaluate the trained model.

## Tools

- Python
- TensorFlow
- Git
- DVC
- Google Drive
